Welcome to your new blog! Every post is a Markdown or MDX file in `src/content/blog/`. A new post shows up in the blog list automatically, is added to the RSS feed, and gets its own social image.

## Write your first post

Create a file such as `src/content/blog/my-first-post.mdx`:

```mdx
---
title: My first post
description: A short introduction to my first blog post.
pubDate: 2026-01-01
---

Write your post here.
```

The post will appear at `/blog/my-first-post`. Start sections with `##`, because the post title is already the main heading.

Set `draft: true` in the frontmatter to see a post during development without publishing it.
