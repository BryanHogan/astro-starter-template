<SectionTitle
    as="h2"
    eyebrow="What is this?"
    title="A simple way to make your website"
/>

This Starter Template provides the complete base for creating a good website which you fully control. You write in Markdown, the resulting pages are performant, accessible and designed following actually modern design principles. The whole project is free and without any unnecessary dependencies.

The setup is simple. Clone the project, add your details to [`src/config.ts`](/blog/customizing-the-design), write your content, and host the generated static site.

You can use the whole project as one complete package, or take only specific things you need for your own web projects.

</section>

The template handles the foundation, while keeping you in control of the content, code, and design.

<Card heading="h3" title="You are in control" icon="padlock">

The code, content, and finished website belong to you. Change anything, host it anywhere, move it whenever you want.

<Card heading="h3" title="Write in Markdown" icon="pencil">

Markdown is easy to write, works in many different apps, and is simple to move elsewhere. It is also a format AI tools understand and work with well.

See the [markdown style guide](/blog/markdown-style-guide) on how to write markdown.

</Card>
<Card heading="h3" title="Fast and performant" icon="rocket">

The static pages use very little JavaScript by default. Images and other content is compressed. No unnecessary libraries or other content is used, so it won't slow the site down. All so your website stays quick.

</Card>
<Card heading="h3" title="Accessible" icon="approve-check-circle">

The project follows modern web development practices and adheres to the Web Content Accessibility Guidelines (WCAG).

So everything including structure, navigation, focus states, and components are built with accessibility in mind.

</Card>
<Card heading="h3" title="Free to use" icon="heart">

The project is free, and you can publish a static website using a free hosting plan from several providers.

</Card>
<Card heading="h3" title="Clean scalable plain CSS styling" icon="setting">

A simple CSS system providing you consistent colors, spacing, typography, layouts, and utilities without adding framework bloat. Making it easy to define one design system. Scalable into anything you need.

Customize the look through one simple [token-based var.css file](/blog/customizing-the-design).

</Card>
<Card heading="h3" title="Components included" icon="puzzle">

Headers, footers, heroes, buttons, cards, icons, callouts, link groups, section titles with eyebrows and more are ready to use and easy to adjust. See the [component showcase](/blog/component-showcase) for more information.

</Card>
<Card heading="h3" title="SEO optimized" icon="magnifier">

SEO optimized, including on-page and technical SEO. Correct semantic usage of elements, optimized components, canonical URLs, social metadata, structured data, and a sitemap to make your website show up on search engines and in AI chats.

Plus a RSS feed also makes it easy for readers to follow new posts.

</Card>

    id="get-started"
    class="padding-top-2xl"
    eyebrow="Get started"
    title="How to use this starter"
/>

<Steps class="margin-top-l">

1. **Create the project.** Run the guided npm setup and answer a few questions about your website.

2. **Review your details.** Check `src/config.ts`, then add social links and optional analytics when you are ready.

3. **Write and publish.** Create your pages in Markdown, adjust the design tokens, and host the generated static site wherever you want.

</Steps>

```bash
npm create @bryanhogan/web-starter@latest
```
