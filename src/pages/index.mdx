This is a starting point for creating a website you fully control. You write in Markdown, the pages are fast and performant, accessibility is built in, and the whole project is free.

Clone the project, add your details to `src/config.ts`, write your content, and host the generated static site. The setup is simple, and static hosting can be free.

Use it as it is, change every part of it, or take only what you need. Make the website you want and, more importantly, one you love using.

    title="Three steps, then make it your own"
/>

<Steps class="margin-top-l">

1. **Get the project.** Clone or download the repository and install the project dependencies.

2. **Add your details.** Update `src/config.ts` with your website name, URL, author details, social links, and analytics settings.

3. **Write and publish.** Create your pages in Markdown or Astro, adjust the design tokens, and host the generated static site wherever you want.

</Steps>
